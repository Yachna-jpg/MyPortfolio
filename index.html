Medi Gone Wild

MediGoneWild is an innovative, full-stack hospital web application. It’s built with a Node.js/Express backend, EJS for dynamic server-side rendering, and a PostgreSQL database hosted on Neon. The core of the app is its robust authentication system (email/password + Google OAuth) and an integrated OpenAI-powered chatbot to assist patients. The entire application is deployed live on Vercel.
